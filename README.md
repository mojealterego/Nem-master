# Nem Master

Production-oriented Unity mobile game foundation inspired by the supplied Coin Master analysis.

## Target
- Unity 6.3 LTS
- Android first
- Data-driven gameplay
- Scalable world/content pipeline
- Mobile performance as a first-class constraint

## Current foundation
- Core game state
- Spin engine
- Energy and coin economy foundation
- ScriptableObject world definitions
- World progression hook
- Unity project context

## Roadmap
1. Boot scene and production UI
2. Village builder
3. Save/migration layer
4. Server-authoritative economy
5. Authentication and cloud sync
6. Addressables + remote world content
7. Shop and Google Play Billing
8. Social/guilds/leaderboards
9. LiveOps/event framework
10. VFX/audio/animation
11. Analytics and anti-cheat
12. Android profiling and release validation

> Generated project skeleton. Unity Editor validation is still required before treating the repository as build-ready.
